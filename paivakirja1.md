# Oppimispäiväkirja: Paikallinen git

__Mikä osion tehtävissä oli vaikeaa ja mikä helppoa? Mikä auttoi minua oppimaan? Miten selvitin esteet?__

Tehtävänannot olivat pääasiassa selkeitä, mutta välillä oli vaikeaa ymmärtää mitä haettiin tai pyydettiin tekemään. Git reset temp.log ei oikein tehnyt mitään.. Jonkin verran omatoimista tiedonhakua ja kurssimateriaalin lukemista uudelleen. 
## Osiossa käyttämäni Git-komennot

| Komento | Kuvaus |
| --------| ------ |
| git add . | talleta kaikki muutetut tiedostot |
| git commit -m "jotain tekstiä" | talletus gitiin |
| git status | tarkastele välitalletusten tilaa tai onko jotain talletettavaa |
| git log | tarkastele talletuksia |
| git temp.log | mitään ei juurikaan tapahtunut, mutta git add . -peruutus |
| git restore jokujoku.txt | tiedoston palauttaminen viimeisimpään muotoon
| git revert f1ffd1ba4 | oli myös haasteita tämän kanssa, mutta talletuksen peruuttaminen |
| git branch -a | haarojen tarkastelu |
| git branch tyylit | uuden haaran luominen | 
| git switch tyylit | siirtyminen uuteen haaraan |
| git switch master | siirtyminen takaisin master haaraan |
| git merge tyylit | haarojen yhdistäminen (siirrytty jo master haaraan)|
| git tag # | harjoituksen merkkaaminen |
