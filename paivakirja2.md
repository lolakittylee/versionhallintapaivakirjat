# Oppimispäiväkirja: Hajautettu git

__Mikä osion tehtävissä oli vaikeaa ja mikä helppoa? Mikä auttoi minua oppimaan? Miten selvitin esteet, jotka vaikuttivat tehtävän suorittamiseen?__

Tehtävä oli mielestäni tarpeeksi haastava, mutta ei vielä alkanut hermoja raastamaan. Jonkin verran oli haasteita ymmärtää, että mitä pitää tehdä. Se ei kuitenkaan onneksi ihan hirveästi vaikeuksia aiheuttanut tällä kertaa. Jotkut komennot eivät toimineet, mutta eivät tuntuneet vaikuttavan tehtävän etenemiseen. 

## Osiossa käyttämäni Git-komennot

| Komento | Kuvaus |
| --------| ------ |
| git remote add origin git@github.com:lolakittylee/versionhallintakurssi.git | liitetään paikallinen ja etärepositoriot |
| git branch -M main | määriteltiin main haara |
| git push -u origin main | määriteltiin main haaralle kulkusuunta |
| git remote -v | tarkastettiin mihin paikallinen repo on yhdistetty |
| git branch new-feat | uuden haaran luominen |
| git switch new-feat | siirtyminen uuteen haaraan |
